Label

class Label

The text of an edge label. The Airflow UI shows the label on the edge in the graph, as it does for Python's Label. The text comes before the task that the label is put on. That way the text sits between the two tasks of the edge in the code, just as the label sits between them in the graph:

loaded.before(Label.of("when empty").on(reportEmpty)); // load >> Label("when empty") >> report_empty
cleaned.after(Label.of("always").on(loaded));          // load >> Label("always") >> cleanup
