Switch

@Target(allowedTargets = [AnnotationTarget.FUNCTION])
annotation class Switch(val id: String = "", val owner: String = "airflow", val startDate: String = "", val endDate: String = "", val triggerRule: String = "all_success", val dependsOnPast: Boolean = false, val ignoreFirstDependsOnPast: Boolean = false, val waitForPastDependsBeforeSkipping: Boolean = false, val waitForDownstream: Boolean = false, val retries: Int = 0, val queue: String = "default", val pool: String = "default_pool", val poolSlots: Int = 1, val executionTimeout: String = "", val retryDelay: String = "PT5M", val retryExponentialBackoff: Double = 0.0, val maxRetryDelay: String = "", val priorityWeight: Int = 1, val weightRule: String = "downstream", val executor: String = "", val doXcomPush: Boolean = true, val emailOnFailure: Boolean = true, val emailOnRetry: Boolean = true, val docMd: String = "", val mapIndexTemplate: String = "", val maxActiveTisPerDag: Int = -1, val maxActiveTisPerDagrun: Int = -1)

Marks a task method that chooses one of several tasks to run; every other one is skipped.

The method returns the class the Dag's builder generated for the task it chose, as Class<? extends Task>. Its wiring-view method returns a SwitchRef, so the cases are listed where the Dag is wired:

@Airflow.Switch(id = "pick_path")
public Class<? extends Task> pickPath(long rows) {
  return rows > 1000 ? EtlBuilder.HandleLong.class : EtlBuilder.HandleShort.class;
}

@Airflow.Deps
static class Wiring implements EtlDeps {
  void depends() { pickPath(extract()).Case(handleLong()).Case(handleShort()); }
}

A switch chooses exactly one case, so a task that runs after several of them needs a trigger rule that tolerates a skipped upstream, such as none_failed_min_one_success.

Configuration attributes are Task's, and apply to the deciding task.
