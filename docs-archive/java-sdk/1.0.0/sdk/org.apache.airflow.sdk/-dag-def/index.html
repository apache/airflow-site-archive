DagDef

class DagDef(val id: String)

A collection of tasks with directional dependencies.

Create a DagDef directly and register TaskDefs with addTask.

The Airflow.Dag annotation should generally be preferred in user code, where the annotation processor generates the wiring for you. Only use this class directly if you need to do low-level plumbing:

var dag = new DagDef("java_etl").config("schedule", "@daily");
var extract = dag.task("extract", Extract.class).config("retries", 2);
extract.before(dag.task("load", Load.class));

Dag and task IDs are validated authoritatively by the Airflow server. This class does not check the characters or length of a Dag or task ID. IDs the server would reject are reported as best-effort build-time warnings by the Gradle plugin's checkAirflowBundle task, which runs BundleInspector against the assembled Bundle.
