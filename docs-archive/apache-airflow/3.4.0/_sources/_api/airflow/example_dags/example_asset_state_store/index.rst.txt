airflow.example_dags.example_asset_state_store
==============================================

.. py:module:: airflow.example_dags.example_asset_state_store

.. autoapi-nested-parse::

   Example Dag that demonstrates using AIP-103 asset state store to track a watermark across DAG runs.
   The producer reads the last watermark, processes only new records, then
   advances the watermark. The consumer is triggered by the asset event and
   reads asset state store to understand what the producer just loaded.

   Asset state store persists on the asset across runs — unlike task state store which is
   scoped to a single task instance. This replaces the common pattern of
   storing watermarks in Airflow Variables, which have no asset-level scoping.
